# Lesson 5 data sources and attribution

* `camera` - `skimage.data.camera()`, downsampled by 2 in each axis.
  Public-domain standard test image redistributed by scikit-image.
* `grass` - `skimage.data.grass()`, top-left 256x256 crop. CC0, from the
  scikit-image data collection.
* `synthetic` - generated in the notebook (see the image cell); no external source.

See https://scikit-image.org/docs/stable/api/skimage.data.html for licensing.

`.gtc` files are the teaching container documented in `imcodec.CONTAINER`.
`.jpg` files are real JPEGs written by Pillow.
